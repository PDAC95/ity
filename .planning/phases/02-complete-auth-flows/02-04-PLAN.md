<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Configure Supabase email templates and Google OAuth</name>
  <files></files>
  <action>
    Configure external services required for auth flows to work.

    **Step 1: Supabase Email Templates**
    1. Go to Supabase Dashboard -> Authentication -> Email Templates
    2. **Confirm signup template:** Update the confirmation URL in the email body to:
       `{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=email&next=/dashboard`
    3. **Reset password template:** Update the recovery URL in the email body to:
       `{{ .SiteURL }}/auth/confirm?token_hash={{ .TokenHash }}&type=recovery&next=/reset-password`
    4. Optionally translate email subject and body text to Spanish

    **Step 2: Supabase Redirect URLs**
    1. Go to Supabase Dashboard -> Authentication -> URL Configuration
    2. Ensure Site URL is set (e.g., http://localhost:8080 for dev)
    3. Add `http://localhost:8080/**` to the Redirect URLs allowlist if not already present

    **Step 3: Google OAuth (if not already configured)**
    1. Go to Google Cloud Console -> APIs & Services -> Credentials
    2. Select your OAuth 2.0 Client ID
    3. Under "Authorized redirect URIs", add:
       `https://<your-supabase-project-ref>.supabase.co/auth/v1/callback`
       (Find your project ref in Supabase Dashboard -> Settings -> General)
    4. Save changes
  </action>
  <verify>User confirms all three steps are complete by typing "configured".</verify>
  <done>Supabase email templates, redirect URLs, and Google OAuth redirect URIs are configured.</done>
</task>
