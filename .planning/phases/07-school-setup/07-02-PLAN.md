**2. Create `ity/apps/web/components/school/branding-tab.tsx`** ('use client'):

- Props: `{ school: { id: string; branding: Branding | null } | null, onDirtyChange: (dirty: boolean) => void }`
- State: `primaryColor` and `accentColor` (initialize from `school?.branding?.primaryColor ?? '#6366F1'` and `school?.branding?.secondaryColor ?? '#EC4899'`)
- Track dirty state: `isDirty = primaryColor !== (school?.branding?.primaryColor ?? '#6366F1') || accentColor !== (school?.branding?.secondaryColor ?? '#EC4899')` — call `onDirtyChange(isDirty)` via useEffect
- Render two `<ColorPicker>` components: "Color primario" and "Color de acento"
- **Live preview section** below color pickers — a mini card showing how colors apply:
  - A sample header bar with `backgroundColor: primaryColor` and white text "Mi Escuela"
  - A sample button with `backgroundColor: accentColor` and white text "Inscribirme"
  - A small card outline with a heading in primaryColor and a badge/pill in accentColor
  - Wrap in a bordered rounded container labeled "Vista previa"
- **Contrast warning:** Implement `hexToRelativeLuminance(hex)` and `contrastRatio(hex1, hex2)` as inline utility functions (see RESEARCH.md). If `contrastRatio(primaryColor, accentColor) < 3.0`, show a yellow warning: `<div className="flex items-center gap-2 text-amber-400 text-sm"><AlertTriangle className="h-4 w-4" /> Los colores seleccionados pueden ser difíciles de distinguir</div>` — warning only, does NOT block save.
- **Save button:** `<button disabled={!isDirty || mutation.isPending}>` with Loader2 spinner
- Mutation: `trpc.schools.updateBranding.useMutation` with input `{ id: school!.id, branding: { primaryColor, secondaryColor: accentColor, font: school?.branding?.font ?? 'inter', logo: school?.branding?.logo, favicon: school?.branding?.favicon } }` — preserve existing logo/favicon/font values.
- onSuccess: `toast.success('Colores guardados', { duration: 3000 })` — update the "clean" reference values to current values (so isDirty becomes false)
- onError: `toast.error('Error al guardar. Inténtalo de nuevo.')`
- If `school === null`, show a message: "Primero guarda el nombre de tu escuela en la pestaña General" — no color pickers.
