- Add `checkSlug` query procedure:
  - Input: `{ slug: z.string().min(3).max(40).regex(/^[a-z0-9-]+$/), currentSchoolId: z.string().uuid().optional() }`
  - Query: `ctx.db.query.schools.findFirst({ where: and(eq(schools.slug, input.slug), ...(input.currentSchoolId ? [ne(schools.id, input.currentSchoolId)] : [])) })`
  - Return: `{ available: !existing }`
- Add `updateSlug` mutation procedure (SEPARATE from `update` — per STATE.md decision):
  - Input: `{ id: z.string().uuid(), slug: z.string().min(3).max(40).regex(/^[a-z0-9-]+$/) }`
  - Re-check uniqueness server-side: query with `and(eq(schools.slug, input.slug), ne(schools.id, input.id))` — if conflict, throw `TRPCError({ code: 'CONFLICT', message: 'este slug ya está en uso' })`
  - Update: `ctx.db.update(schools).set({ slug: input.slug, updatedAt: new Date() }).where(and(eq(schools.id, input.id), eq(schools.creatorId, ctx.user.id))).returning()`
  - If no row returned, throw `TRPCError({ code: 'NOT_FOUND' })`
