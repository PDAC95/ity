**3. Create `ity/packages/api/src/routers/creators.ts`:**

New router with two procedures:
- `get`: protectedProcedure query — `ctx.db.query.creators.findFirst({ where: eq(creators.id, ctx.user.id) })`. Throw TRPCError NOT_FOUND if no creator.
- `update`: protectedProcedure mutation with input schema:
  - `name`: z.string().min(1).max(50).optional()
  - `bio`: z.string().max(500).optional().nullable()
  - `contactEmail`: z.string().email().optional().nullable()
  - `socialLinks`: z.object({ instagram, x, youtube, tiktok, linkedin, facebook — all z.string().max(100).optional() }).optional().nullable()
  
  Strip leading `@` from social link values before saving (TikTok/YouTube users may include it). Update with `{ ...input, updatedAt: new Date() }` using `eq(creators.id, ctx.user.id)` and `.returning()`. Throw TRPCError NOT_FOUND if no rows updated.

Import `router, protectedProcedure` from `../trpc`, `TRPCError` from `@trpc/server`, `creators` from `@ity/db`, `eq` from `drizzle-orm`, `z` from `zod`.

**4. Register in `ity/packages/api/src/root.ts`:**
