## Decisions Made

- Content area background: `#f8f8f8` → `#1e1e22`. Notch SVG fill updated simultaneously per Pitfall 4.
- All CTA/submit buttons: `bg-indigo-600 text-white hover:bg-indigo-500` → `bg-[#bfdbfe] text-zinc-900 hover:bg-[#93c5fd]`
- All input focus rings: `focus:ring-1 focus:ring-indigo-500 focus:border-indigo-500` → `focus:ring-2 focus:ring-[#bfdbfe]/30 focus:border-[#bfdbfe]`

- Loading state: Replaced static label with `{isPending ? <><Loader2 .../> Guardando...</> : 'Guardar cambios'}` pattern on all submit buttons
