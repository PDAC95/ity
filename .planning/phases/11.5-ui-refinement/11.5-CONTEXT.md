# Phase 11.5: UI Refinement - Context

**Gathered:** 2026-04-15
**Status:** Ready for planning

<domain>
## Phase Boundary

Refinar toda la interfaz para que se vea profesional, consistente y moderna. El frontend actual tiene un estilo muy basico que no transmite confianza como producto SaaS. Esta fase NO agrega funcionalidad nueva — solo pule lo que existe para que se sienta como producto real.

El layout base (header arriba + dock de acciones rapidas abajo) ya fue rediseñado por el usuario y debe mantenerse como base.

</domain>

<decisions>
## Implementation Decisions

### Tema dark y paleta de colores
- Fondos gris oscuro estilo zinc: background #18181b (zinc-900), surface #1e1e22, card #27272a, border #3f3f46
- Color de acento principal: pastel azul #bfdbfe (del dock de acciones rapidas existente)
- Los demas pasteles del dock (#c4f0c2, #f5c2d6, #fef3c7, #ddd6fe, #fbcfe8) se mantienen solo en el dock — el resto de la app usa #bfdbfe como acento unico
- Bordes sutiles zinc-700/zinc-800 entre cards y secciones
- Colores semanticos en version pastel: success #a7f3d0, error #fecaca, warning #fef3c7, info #bfdbfe
- Texto principal atenuado: headings zinc-100, body zinc-300, secondary zinc-400, muted zinc-500
- Botones CTA: texto oscuro (zinc-900) sobre fondo pastel azul (#bfdbfe), hover #93c5fd
- Botones secundarios: bg-zinc-800 text-zinc-200, hover bg-zinc-700
- Botones ghost: text-zinc-400 hover:text-zinc-200

### Chat wizard premium
- Indicador de progreso: barra de pasos horizontal (stepper) con pasos numerados, paso actual resaltado con pastel azul
- Header del chat: muestra nombre de la escuela (si ya se capturo) + paso actual + boton cerrar
- Mensajes: burbujas diferenciadas — AI a la izquierda bg-zinc-800 border-zinc-700 con avatar, usuario a la derecha bg-[#bfdbfe]/10
- Indicador de typing: tres dots animados pulsantes tipo iMessage dentro de burbuja AI
- Quick replies: chips/pills con bg-zinc-800 border-zinc-700, hover bg-[#bfdbfe]/10
- Animaciones de entrada: fadeIn + slideUp (opacity 0→1, translateY 8px→0, 200ms ease-out)
- Input del chat: redondeado (rounded-xl), bg-zinc-800/50 border-zinc-700, boton enviar bg-[#bfdbfe] text-zinc-900

### Formularios y feedback
- Errores: inline bajo el input, texto color #fecaca (red-200), borde del input cambia a rojo pastel
- Exito: checkmark + borde verde pastel (#a7f3d0) al completar campo valido
- Inputs normales: bg-zinc-800 border-zinc-700, focus con ring-2 ring-[#bfdbfe]/30
- Labels: fijos arriba del input (no flotantes), text-zinc-400 text-sm
- Botones submit loading: spinner + texto cambia a "Guardando...", boton se deshabilita
- Validacion: al blur + submit (no en tiempo real mientras escribe)
- Toasts/notificaciones: arriba a la derecha, bg-zinc-800 border-l-4 con color semantico, auto-dismiss 3 segundos

### Dashboard shell y layout
- Layout base: header principal arriba + dock de acciones rapidas abajo — YA REDISEÑADO, mantener como esta
- Header: mantener estilo actual, solo asegurar consistencia con el tema dark
- Area de contenido: scroll interno (header y dock fijos, contenido scrollea entre ambos)
- Ancho del contenido: full width con padding lateral generoso
- Transiciones de pagina: fadeIn sutil (opacity 0→1, 150ms, ease-out)
- Cards: bg-zinc-800/50 border-zinc-700, hover border-zinc-600 + hover bg-zinc-800
- Empty states: icono grande + texto motivacional + boton CTA pastel
- Loading: skeletons con shimmer que replican la forma del contenido real (bg-zinc-800 animate-pulse)

### Claude's Discretion
- Exacto spacing/padding entre secciones
- Tipografia: escala y font weights especificos
- Diseño especifico de los skeletons por pagina
- Animaciones de hover en cards (escala, timing)
- Diseño de los iconos en empty states
- Orden y agrupacion de items en el dock (ya definido por usuario)

</decisions>

<specifics>
## Specific Ideas

- Los colores pastel del dock de acciones rapidas son la identidad visual de la app — mantenerlos como splash de color sobre el tema dark zinc
- Los 6 pasteles del dock: Mi Pagina #c4f0c2, Escuela #f5c2d6, Chat AI #fef3c7, Perfil #bfdbfe, Cursos #ddd6fe, Alumnos #fbcfe8
- El layout header+dock ya esta rediseñado y es la base — no cambiar la estructura, solo pulir estilos
- Consistencia total: todos los inputs, botones, cards, y estados deben seguir el mismo patron de colores y bordes en toda la app (auth, dashboard, chat, forms)

</specifics>
