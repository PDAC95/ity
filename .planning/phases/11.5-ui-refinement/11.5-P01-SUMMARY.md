## Changes Made

### Task 1: Layout + Shared Components

**layout.tsx:**
- Left panel: `bg-gradient-to-br from-blue-600 via-blue-700 to-indigo-800` → `bg-zinc-950 border-r border-zinc-800`
- ITY wordmark: `text-white` → `text-[#bfdbfe]`
- Supporting text: `text-blue-200` / `text-blue-100/80` → `text-zinc-400`
- Stats dividers: `bg-blue-400/30` → `bg-zinc-700`
- Right panel: added `bg-zinc-900` to outermost wrapper (mobile dark fix)
- Mobile logo: `text-gray-900` → `text-[#bfdbfe]`, `text-gray-500` → `text-zinc-400`

**password-input.tsx:**
- Input: `border-gray-300 focus:border-blue-500 focus:ring-blue-500` → `border-zinc-700 bg-zinc-800 text-zinc-100 placeholder:text-zinc-500 focus:border-[#bfdbfe] focus:ring-[#bfdbfe]/30`
- Label: `text-gray-700` → `text-zinc-400`
- Toggle icon: `text-gray-400 hover:text-gray-600` → `text-zinc-400 hover:text-zinc-200`
- Error: `text-red-600` → `text-[#fecaca]`

**social-button.tsx (GoogleAuthButton):**
- Button: `border-gray-300 bg-white text-gray-700 hover:bg-gray-50 focus:ring-gray-200` → `border-zinc-700 bg-zinc-800 text-zinc-200 hover:bg-zinc-700 focus:ring-[#bfdbfe]/30`
- Spinner: `border-gray-300 border-t-gray-600` → `border-zinc-600 border-t-zinc-200`

**divider.tsx (AuthDivider):**
- Line: `border-gray-200` → `border-zinc-700`
- Text span: `bg-white text-gray-400` → `bg-zinc-900 text-zinc-500`

### Task 2: Auth Page Forms (5 pages)

All 5 pages received identical mechanical substitutions:
- Input fields: `border-gray-300 bg-white text-gray-900` → `border-zinc-700 bg-zinc-800 text-zinc-100 placeholder:text-zinc-500`
- Focus rings: `focus:border-blue-500 focus:ring-blue-500` → `focus:border-[#bfdbfe] focus:ring-[#bfdbfe]/30`
- Labels: `text-gray-700` → `text-zinc-400`
- CTA buttons: `bg-blue-600 text-white hover:bg-blue-700` → `bg-[#bfdbfe] text-zinc-900 hover:bg-[#93c5fd]`
- Error messages: `bg-red-50 p-3 rounded-lg text-red-600` → inline `text-[#fecaca]` (no background)
- Links: `text-blue-600 hover:text-blue-500` → `text-[#bfdbfe] hover:text-[#93c5fd]`
- Headings: `text-gray-900` → `text-zinc-100`
- Secondary text: `text-gray-500` → `text-zinc-400`, `text-gray-400` → `text-zinc-500`
- Loading state: custom border spinners → `<Loader2 className="h-4 w-4 animate-spin" />` + "Guardando..."
- Icon circles (Mail, ShieldCheck): `bg-blue-50` → `bg-zinc-800`, icons `text-blue-600` → `text-[#bfdbfe]`
